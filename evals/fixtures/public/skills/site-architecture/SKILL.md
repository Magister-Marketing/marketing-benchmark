# Site architecture

Arrange sections in the order a cautious visitor needs them: relevance,
mechanism, included value, risk or limitations, objections, then the next step.
Give every section one job and a descriptive heading. Avoid duplicate sections
and unsupported navigation depth. The deliverable is a reviewable information
architecture and copy draft, not a deployed site.

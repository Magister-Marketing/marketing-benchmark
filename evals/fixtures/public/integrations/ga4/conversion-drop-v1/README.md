# Synthetic GA4 conversion-drop fixture

This redistribution-safe fixture contains no customer or vendor data. It models
two complete weeks for a fictional B2B SaaS company. Sessions are nearly flat,
while purchases fall primarily on the Paid Search `/pricing` segment. The data
supports a prioritized hypothesis, not a causal conclusion.

The agent-visible MCP server receives `manifest.json`, `tools.json`,
`dataset.json`, and `script.json`. `oracle.json` is staged separately and is
available only to offline graders after the agent attempt finishes.
